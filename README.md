
# PHP & MySQL Web Application

## Overview

This project is a dynamic web application built using PHP and MySQL to manage and persist structured data through a browser interface. The aim was to strengthen my backend development skills by handling server-side logic, database interaction, and dynamic content generation within a full-stack environment.

The application connects a user-facing interface with a relational database, allowing data to be created, retrieved, updated, and deleted through structured workflows.

## Architecture and Design

The system follows a clear separation between frontend presentation and backend processing. PHP is responsible for handling HTTP requests, validating user input, interacting with the MySQL database, and returning dynamic responses.

The database layer is structured to support reliable CRUD operations while maintaining data integrity. Queries are written to efficiently retrieve and manipulate records, and the application logic ensures consistent communication between the server and database.

Key design considerations included:

* Secure database connectivity
* Input validation and sanitisation
* Structured query execution
* Clear separation of concerns
* Maintainable file organisation

## Core Functionality

* Server-side form handling (GET and POST requests)
* MySQL database integration
* CRUD operations (Create, Read, Update, Delete)
* Dynamic rendering of database-driven content
* Structured navigation between application pages

The backend ensures that user actions are processed reliably and that the database state remains consistent.

## Key Concepts Applied

* PHP server-side scripting
* MySQL relational database integration
* SQL query construction and execution
* Data validation and security practices
* Full request-response lifecycle handling

## Outcome

This project strengthened my understanding of backend web development and database-driven applications. It demonstrates the ability to design, implement, and manage a structured PHP and MySQL system that handles real user interaction and persistent data storage.
